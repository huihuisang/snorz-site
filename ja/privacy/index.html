プライバシーバイデザイン

プライバシー ポリシー

ぐっすり は単純な原則に基づいて構築されています。つまり、何かを共有するという明確な選択をしない限り、寝室での夜はプライベートなままにしておく必要があります。

2026 年 8 月 15 日より発効 · ぐっすり iOS アプリとこの Web サイトに適用されます

1.概要

このプライバシー ポリシーでは、ぐっすり がどのような情報を処理するのか、その情報が処理される理由、保存される場所、および利用できる選択肢について説明します。

  • 音声分析は iPhone 上で実行されます。
  • 沈黙は意図的に保存されることはありません。
  • いびきをかく可能性のあるイベントはクリップとしてローカルに保存されるので、確認することができます。
  • プライベート iCloud 同期はオプションです。
  • Discover の共有はオプションであり、明示的に選択したクリップにのみ適用されます。
  • ぐっすり はサードパーティの広告トラッカーを使用せず、個人情報を販売しません。

2.マイク音声、録音、レポート

あなたの許可を得て、ぐっすり はアクティブな睡眠セッション中に iPhone のマイクを使用します。ライブオーディオストリームはデバイス上で分析され、いびきの可能性のある音を特定します。

記憶に残るもの

分析には継続的なライブ ストリームが使用されます。 ぐっすり は、一晩中の生の録音や無音として分類された期間を意図的に保存しません。

デバイスに保存される可能性のあるもの

  • いびきの可能性があると特定されたイベントの音声クリップ
  • セッションの開始時刻と終了時刻
  • 検出されたイベントのタイミングと期間
  • 相対ラウドネス測定
  • 分析範囲と信頼性情報
  • 報告されるオプションの睡眠姿勢
  • Snore Load と関連する非診断傾向データ

この情報は、夜間レポート、カレンダー、タイムライン、ウィジェット、長期パターンの作成に使用されます。

3.オプションのプライベート iCloud 同期

iCloud 同期を有効にすると、ぐっすり は録音データのプライベート コピーを Apple CloudKit に保存し、他のデバイスで利用できるようにします。オンデバイス データベースはプライマリ ローカル コピーのままです。

CloudKit のプライベート データは Apple アカウントに関連付けられており、 Apple のプライバシー ポリシーに基づいて Apple によって処理されます。 ぐっすり は Apple アカウントのパスワードを受け取りません。

ぐっすり 設定で iCloud 同期を無効にすることができます。アプリ内のすべての睡眠データを削除すると、対応するプライベート CloudKit レコードの削除も要求されます。

4.発見して公開共有

Discover はオプションのコミュニティ機能です。 Discover の閲覧では、プライベートな睡眠データは公開されません。

公開プロフィールを作成するか、Discover と対話する場合、ぐっすり は以下を処理する場合があります。

  • 選択した公開ユーザー名とその変更履歴
  • 公開するために明示的に選択した特定のオーディオ イベント クリップ
  • クリップの Sound Match、長さ、相対的な音量、投稿時間
  • 公開投稿に対するあなたの反応
  • 公開コンテンツに関して送信したレポート
  • プロフィールとやり取りの一貫性を保つために、iCloud ユーザー レコードから派生したプライバシー保護識別子

公開されたクリップとユーザー名はパブリック CloudKit データベースに保存され、他の ぐっすり ユーザーが聞いたり見たりすることができます。完全な夜間レポート、選択されていないクリップ、睡眠位置、プライベート トレンド履歴は、Discover 投稿には含まれません。

共有は慎重に行ってください: 音声には音声や特定の背景情報が含まれる場合があります。公開する前に聞いて、音声や個人情報が存在する可能性がある人から許可を得てください。

アプリ内で自分の公開投稿を削除できます。コンテンツを報告したり、クリエイターをブロックしたりすることもできます。 ぐっすり は、安全性、ポリシーの施行、または法令順守のために必要な場合、公開コンテンツを削除することがあります。

5.購入と ぐっすり Pro

Apple は App Store での購入を処理します。 ぐっすり は RevenueCat を使用して製品を取得し、購入フローを完了し、購入を復元し、ぐっすり Pro 資格が有効かどうかを判断します。

これらの目的のために、Apple と RevenueCat は、購入サービスの提供と保護に必要なトランザクション ID、サブスクリプション ステータス、アプリ ユーザー ID、デバイスまたはアプリの技術情報を処理することがあります。 ぐっすり は、支払いカードの完全な詳細を受け取りません。

詳細については、 Apple のプライバシー ポリシー および RevenueCat のプライバシー ポリシーをご覧ください。

6.この Web サイトとサポート リクエスト

この静的 Web サイトは GitHub Pages でホストされています。 GitHub は、サービスを運用および保護するために、IP アドレス、ブラウザの種類、要求されたページ、アクセス時間などの通常のサーバー ログ情報を受信する場合があります。 ぐっすり は、分析 Cookie、広告ピクセル、行動追跡スクリプトをこの Web サイトに追加しません。

support@ajigu.com にメールを送信すると、Cloudflare がメッセージを転送し、Google がサポート受信箱をホストし、Resend が返信を配信する場合があります。これらのサービス提供者は、それぞれのプライバシー条件に基づいて情報を非公開で取り扱います。問題の解決に必要な場合を除き、録音、健康情報、購入レシート、Apple Account の詳細、その他の機密性の高い個人情報を含めないでください。

GitHub はウェブサイトデータを次の規約に基づいて処理します： GitHub の一般的なプライバシーに関する声明に基づいて Web サイトとサポート データを処理します。

7.情報の使用方法

ぐっすり は、次の目的で必要な場合にのみ情報を処理します。

  • いびきの可能性を検出し、リクエストしたレポートを作成します
  • クリップを再生、整理、保持、同期、削除する
  • ウィジェット、トレンド、ぐっすり Pro 機能を提供する
  • Discover のプロフィール、投稿、反応、ブロック、レポートを操作する
  • サブスクリプションの処理と復元
  • セキュリティを維持し、不正行為を防止し、適用される義務を遵守する
  • あなたが開始したサポートとプライバシーのリクエストに対応する

8.情報が共有されるとき

情報は次の状況でのみ共有されます。

  • あなたの指示: iCloud 同期を有効にするとき、または選択したクリップを Discover に公開するとき。
  • サービスプロバイダーの場合: Apple はマイク、App Store、CloudKit の各サービスを提供し、RevenueCat はサブスクリプション権限の基盤を提供し、GitHub は本ウェブサイトをホストし、Cloudflare、Google、Resend はサポートメールを処理します。
  • 安全性または法的理由: ポリシーの施行、ユーザーの保護、法的要求への対応、または法律の遵守のために合理的に必要な場合
  • 事業譲渡中: アプリが再編成、買収、譲渡される場合、適切な通知と保護措置が適用されます。

ぐっすり は、あなたの録音や個人情報を販売したり、第三者の広告に使用したりすることはありません。

9.保持、削除、および選択

  • セッションの概要は、削除するまでデバイス上に残ります。
  • 再生可能なクリップは、7 日、30 日、90 日など、アプリで利用可能な保存オプションに従い、または削除されるまで保持されます。
  • iCloud のプライベート コピーは、同期が有効になっている間、および Apple の通常のバックアップおよびサービス プロセスに従って、対応するデータが削除されるまで保持されます。
  • Discover の公開投稿は、ユーザーが削除するか、管理、安全、または法的な理由で削除されるまで残ります。
  • 定期購入記録は、Apple と RevenueCat によって法的および運用上の要件に従って保管されます。
  • サポートメールは、返信、安全の維持、法的義務への対応に合理的に必要な期間のみ、サポート受信箱に保持されます。

ぐっすり 内から個々のイベント、公開投稿、またはすべての睡眠データを削除できます。 iPhone の設定でマイクへのアクセスを削除したり、ぐっすり の設定で iCloud 同期を無効にしたり、Apple アカウントの設定でサブスクリプションを管理したりできます。

10.セキュリティ

ぐっすり は、プラットフォームのセキュリティ機能、ローカル アプリ ストレージ、Apple CloudKit コントロール、限定的なデータ収集を使用してリスクを軽減します。完全に安全であることを保証できるストレージや伝送システムはありません。デバイスと Apple アカウントを保護し、機密の録音を公開しないでください。

11.子供たち

ぐっすり は、子供が親または保護者なしで音声を公に公開することを目的としていません。お住まいの国でデジタル サービスに同意できる年齢に達していない場合は、親または保護者の許可がある場合にのみ Discover を使用してください。お子様が個人情報を公開したと思われる親または保護者は、以下の非公開報告チャネルを通じて当社にご連絡ください。

12.国際処理

Apple、RevenueCat、および GitHub は、お客様が居住している国以外の国で情報を処理する場合があります。それぞれのプライバシー ステートメントでは、サービスに適用される保護措置と場所について説明しています。

13.このポリシーの変更

このポリシーは、ぐっすり が変更された場合、または法的および運用上の要件が進化した場合に更新される可能性があります。このページの上部にある発効日は、新しいバージョンが発行されると変更されます。重要な変更は、アプリ内または App Store のリリース情報を通じて通知される場合もあります。

14.連絡先

一般的な質問、プライバシー、安全、セキュリティに関するお問い合わせは support@ajigu.com までメールしてください。問題の解決に必要な場合を除き、機密情報を含めないでください。
