隱私權政策

睡好 圍繞著一個簡單的原則構建：除非您明確選擇分享某些內容，否則在臥室度過的夜晚應該保持私密性。

2026 年 8 月 15 日生效 · 適用於 睡好 iOS 應用程式和本網站

在此頁面 概述 音頻和報告 iCloud Sync Discover 購買 網址 如何使用數據 分享 保留與控制 安全性 兒童 更改 聯絡方式

1。概述

本隱私權政策解釋了 睡好 處理哪些資訊、處理這些資訊的原因、儲存這些資訊的位置以及您可以選擇的資訊。

  • 音訊分析在您的 iPhone 上運行。
  • 沉默從來都不是有意儲存的。
  • 可能的打鼾事件會以剪輯形式儲存在本地，以便您查看。
  • 私人 iCloud 同步是可選的。
  • 發現共享是可選的，並且僅適用於您明確選擇的剪輯。
  • 睡好 不使用第三方廣告追蹤器，也不出售個人資訊。

2。麥克風音訊、錄音和報告

經過您的許可，睡好 會在睡眠期間使用 iPhone 麥克風。在裝置上分析即時音訊串流，以識別可能打鼾的聲音。

記憶體中保留的內容

使用連續直播進行分析。 睡好 不會有意保存整夜的原始錄音或歸類為靜音的時間段。

您的裝置上可能儲存的內容

  • 被辨識為可能打鼾的事件的音訊剪輯
  • 會話開始和結束時間
  • 偵測到的事件時間和持續時間
  • 相對響度測量
  • 分析覆蓋範圍和置信度資訊
  • 您可選報告的睡眠位置
  • Snore Load 及相關非診斷趨勢資料

此資訊用於建立夜間報告、日曆、時間軸、小部件和長期模式。

3。可選的私人 iCloud 同步

如果您啟用 iCloud 同步，睡好 會在 Apple CloudKit 中儲存您的錄音資料的私人副本，以便在您的其他裝置上使用。您的裝置上資料庫仍然是主要本機副本。

私人 CloudKit 資料與您的 Apple 帳戶相關聯，並由 Apple 根據 Apple 隱私權政策進行處理。 睡好 沒有收到您的 Apple 帳戶密碼。

您可以在 睡好 設定中停用 iCloud 同步。刪除應用程式中的所有睡眠資料也會要求刪除對應的私人 CloudKit 記錄。

4。發現並公開分享

發現是一項可選的社群功能。瀏覽發現不會發布您的私人睡眠數據。

如果您建立公開個人資料或與 Discover 互動，睡好 可能會處理：

  • 您選擇的公共使用者名稱及其變更歷史記錄
  • 您明確選擇發佈的特定音訊事件剪輯
  • 剪輯的 Sound Match、持續時間、相對響度和發佈時間
  • 您對公開貼文的反應
  • 您提交的有關公開內容的報告
  • 從您的 iCloud 使用者記錄中派生的隱私保護標識符，用於保持個人資料和互動的一致性

發布的剪輯和使用者名稱儲存在公共 CloudKit 資料庫中，其他 睡好 使用者可以聽到或看到。您的完整夜間報告、未選擇的剪輯、睡眠姿勢和私人趨勢歷史記錄不包含在「發現」貼文中。

小心分享： 音訊可以包含語音或辨識背景資訊。在發布之前先聆聽並獲得可能存在聲音或私人資訊的任何人的許可。

您可以在應用程式中刪除自己的公開貼文。您也可以舉報內容或封鎖創建者。出於安全、政策執行或法律合規性需要，睡好 可能會刪除公共內容。

5。購買和 睡好 Pro

Apple 處理 App Store 購買。 睡好 使用 RevenueCat 檢索產品、完成購買流程、恢復購買並確定 睡好 Pro 權利是否有效。

出於這些目的，Apple 和 RevenueCat 可能會處理交易識別碼、訂閱狀態、應用程式使用者識別碼以及提供和保護購買服務所需的裝置或應用程式技術資訊。 睡好 沒有收到您完整的支付卡詳細資訊。

如需了解更多信息，請參閱 Apple 隱私權政策 和 RevenueCat 隱私權政策。

6。本網站和支援請求

此靜態網站由 GitHub Pages 託管。 GitHub 可能會接收普通的伺服器日誌訊息，例如 IP 位址、瀏覽器類型、請求的頁面以及存取時間以操作和保護服務。 睡好 不會在本網站上新增分析 Cookie、廣告像素或行為追蹤腳本。

如果您傳送電子郵件至 support@ajigu.com，Cloudflare 會轉送郵件，Google 代管支援收件匣，Resend 可能用於傳送回覆。這些服務供應商會依各自的隱私條款私密處理資訊。除非解決問題確有必要，否則請勿提供錄音、健康資訊、購買收據、Apple 帳號詳細資料或其他敏感個人資訊。

GitHub 依據以下聲明處理網站資料： GitHub 一般隱私聲明處理網站和支援資料。

7。如何使用資訊

睡好 僅根據需要處理資訊：

  • 偵測可能打鼾的情況並產生您要求的報告
  • 播放、整理、保留、同步或刪除您的片段
  • 提供小工具、趨勢和 睡好 Pro 功能
  • 操作「發現」個人資料、貼文、反應、封鎖和報告
  • 處理與恢復訂閱
  • 維護安全、防止濫用並遵守適用的義務
  • 回應您發起的支援和隱私要求

8。何時分享資訊

僅在以下情況下共享資訊：

  • 按照您的指示 ：當您啟用 iCloud 同步或將選定的剪輯發佈到「發現」時。
  • 與服務供應商合作： Apple 提供麥克風、App Store 與 CloudKit 服務；RevenueCat 提供訂閱權益基礎架構；GitHub 代管本網站；Cloudflare、Google 與 Resend 處理支援郵件。
  • 出於安全或法律原因 ：在執行政策、保護使用者、回應合法請求或遵守法律的合理必要時。
  • 業務轉移期間 ：如果應用程式被重組、收購或轉讓，須遵守適當的通知和保障措施。

睡好 不會出售您的錄音或個人訊息，也不會將其用於第三方廣告。

9。保留、刪除和您的選擇

  • 會話摘要會保留在您的裝置上，直到您將其刪除。
  • 可播放的剪輯將遵循應用程式中提供的保留選項，例如 7、30 或 90 天，或直到您刪除它們為止。
  • 在啟用同步期間，直到相應資料被刪除之前，私人 iCloud 副本都會保留，具體取決於 Apple 的正常備份和服務流程。
  • 公開發現貼文會保留，直到您將其刪除或出於審核、安全或法律原因而將其刪除為止。
  • 訂閱記錄由 Apple 和 RevenueCat 根據其法律和營運要求保留。
  • 支援郵件只會在回覆請求、維護安全及履行法律義務所合理需要的期間內保留於支援收件匣。

您可以從 睡好 中刪除單一事件、公開貼文或所有睡眠資料。您可以在 iPhone 設定中刪除麥克風存取權限，在 睡好 設定中停用 iCloud 同步，以及在 Apple 帳戶設定中管理訂閱。

10。安全性

睡好 使用平台安全功能、本機應用程式儲存、Apple CloudKit 控制項和有限的資料收集來降低風險。任何儲存或傳輸系統都無法保證完全安全。保護您的裝置和 Apple 帳戶，不要發布敏感錄音。

11。兒童

睡好 不適合兒童在沒有父母或監護人的情況下公開發布音訊。如果您未達到所在國家/地區可以同意使用數位服務的年齡，請僅在父母或監護人的許可下使用 Discover。認為孩子公開了個人資訊的家長或監護人應透過以下的私人舉報管道與我們聯繫。

12。國際加工

Apple、RevenueCat 和 GitHub 可能會在您居住地以外的國家處理資訊。他們各自的隱私權聲明解釋了適用於其服務的保護措施和地點。

13。本政策的變更

當 睡好 發生變化或法律和營運要求發生變化時，本政策可能會更新。當新版本發佈時，本頁頂部的生效日期將被修改。重大變更也可能在應用程式中或透過應用程式商店發布訊息進行傳達。

14。聯絡方式

如有一般、隱私、安全或資訊安全相關問題，請傳送電子郵件至 support@ajigu.com。除非解決問題確有必要，否則請勿提供敏感資訊。
