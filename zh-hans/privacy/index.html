隐私设计

隐私政策

Snorz 围绕一个简单的原则构建：除非您明确选择分享某些内容，否则在卧室度过的夜晚应该保持私密性。

2026 年 8 月 15 日生效 · 适用于 Snorz iOS 应用程序和本网站

在此页面 概述 音频和报告 iCloud Sync Discover 购买 网站 如何使用数据 分享 保留和控制 安全 儿童 更改 联系方式

1。概述

本隐私政策解释了 Snorz 处理哪些信息、处理这些信息的原因、存储这些信息的位置以及您可以选择的信息。

  • 音频分析在您的 iPhone 上运行。
  • 沉默从来都不是有意储存的。
  • 可能的打鼾事件会以剪辑形式存储在本地，以便您查看。
  • 私人 iCloud 同步是可选的。
  • 发现共享是可选的，并且仅适用于您明确选择的剪辑。
  • Snorz 不使用第三方广告跟踪器，也不出售个人信息。

2。麦克风音频、录音和报告

经过您的许可，Snorz 会在睡眠期间使用 iPhone 麦克风。在设备上分析实时音频流，以识别可能打鼾的声音。

内存中保留的内容

使用连续直播进行分析。 Snorz 不会有意保存整夜的原始录音或归类为静音的时间段。

您的设备上可能保存的内容

  • 被识别为可能打鼾的事件的音频剪辑
  • 会话开始和结束时间
  • 检测到的事件时间和持续时间
  • 相对响度测量
  • 分析覆盖范围和置信度信息
  • 您可选报告的睡眠位置
  • Snore Load 及相关非诊断趋势数据

此信息用于创建夜间报告、日历、时间线、小部件和长期模式。

3。可选的私人 iCloud 同步

如果您启用 iCloud 同步，Snorz 会在 Apple CloudKit 中存储您的录音数据的私人副本，以便在您的其他设备上使用。您的设备上数据库仍然是主要本地副本。

私有 CloudKit 数据与您的 Apple 帐户相关联，并由 Apple 根据 Apple 隐私政策进行处理。 Snorz 没有收到您的 Apple 帐户密码。

您可以在 Snorz 设置中禁用 iCloud 同步。删除应用中的所有睡眠数据也会请求删除相应的私有 CloudKit 记录。

4。发现并公开分享

发现是一项可选的社区功能。浏览发现不会发布您的私人睡眠数据。

如果您创建公开个人资料或与 Discover 互动，Snorz 可能会处理：

  • 您选择的公共用户名及其更改历史记录
  • 您明确选择发布的特定音频事件剪辑
  • 剪辑的 Sound Match、持续时间、相对响度和发布时间
  • 您对公开帖子的反应
  • 您提交的有关公开内容的报告
  • 从您的 iCloud 用户记录中派生的隐私保护标识符，用于保持个人资料和互动的一致性

发布的剪辑和用户名存储在公共 CloudKit 数据库中，其他 Snorz 用户可以听到或看到。您的完整夜间报告、未选择的剪辑、睡眠姿势和私人趋势历史记录不包含在“发现”帖子中。

小心分享： 音频可以包含语音或识别背景信息。在发布之前先聆听并获得可能存在声音或私人信息的任何人的许可。

您可以在应用程序中删除自己的公开帖子。您还可以举报内容或阻止创建者。出于安全、政策执行或法律合规性需要，Snorz 可能会删除公共内容。

5。购买和 Snorz Pro

Apple 处理 App Store 购买。 Snorz 使用 RevenueCat 检索产品、完成购买流程、恢复购买并确定 Snorz Pro 权利是否有效。

出于这些目的，Apple 和 RevenueCat 可能会处理交易标识符、订阅状态、应用程序用户标识符以及提供和保护购买服务所需的设备或应用程序技术信息。 Snorz 没有收到您完整的支付卡详细信息。

如需了解更多信息，请参阅 Apple 隐私政策 和 RevenueCat 隐私政策。

6。本网站和支持请求

此静态网站由 GitHub Pages 托管。 GitHub 可能会接收普通的服务器日志信息，例如 IP 地址、浏览器类型、请求的页面以及访问时间以操作和保护服务。 Snorz 不会向本网站添加分析 Cookie、广告像素或行为跟踪脚本。

如果您向 support@ajigu.com 发送邮件，Cloudflare 会转发邮件，Google 托管支持收件箱，Resend 可能用于发送回复。这些服务提供商会依据各自的隐私条款私密处理信息。除非解决问题确有必要，否则请勿提供录音、健康信息、购买凭证、Apple 账户详情或其他敏感个人信息。

GitHub 依据以下声明处理网站数据： GitHub 一般隐私声明处理网站和支持数据。

7。如何使用信息

Snorz 仅根据需要处理信息：

  • 检测可能打鼾的情况并生成您要求的报告
  • 播放、整理、保留、同步或删除您的剪辑
  • 提供小部件、趋势和 Snorz Pro 功能
  • 操作“发现”个人资料、帖子、反应、屏蔽和报告
  • 处理和恢复订阅
  • 维护安全、防止滥用并遵守适用的义务
  • 回应您发起的支持和隐私请求

8。何时共享信息

仅在以下情况下共享信息：

  • 按照您的指示 ：当您启用 iCloud 同步或将选定的剪辑发布到“发现”时。
  • 与服务提供商合作： Apple 提供麦克风、App Store 和 CloudKit 服务；RevenueCat 提供订阅权益基础设施；GitHub 托管本网站；Cloudflare、Google 和 Resend 处理支持邮件。
  • 出于安全或法律原因 ：在执行政策、保护用户、响应合法请求或遵守法律的合理必要时。
  • 业务转让期间 ：如果应用被重组、收购或转让，须遵守适当的通知和保障措施。

Snorz 不会出售您的录音或个人信息，也不会将其用于第三方广告。

9。保留、删除和您的选择

  • 会话摘要会保留在您的设备上，直到您将其删除。
  • 可播放的剪辑将遵循应用中提供的保留选项，例如 7、30 或 90 天，或者直到您删除它们为止。
  • 在启用同步期间，直到相应数据被删除之前，私人 iCloud 副本都会保留，具体取决于 Apple 的正常备份和服务流程。
  • 公开发现帖子会一直保留，直到您将其删除或出于审核、安全或法律原因而将其删除为止。
  • 订阅记录由 Apple 和 RevenueCat 根据其法律和运营要求保留。
  • 支持邮件仅会在回复请求、维护安全和履行法律义务所合理需要的期间内保留在支持收件箱中。

您可以从 Snorz 中删除单个事件、公共帖子或所有睡眠数据。您可以在 iPhone 设置中删除麦克风访问权限，在 Snorz 设置中禁用 iCloud 同步，以及在 Apple 帐户设置中管理订阅。

10。安全性

Snorz 使用平台安全功能、本地应用存储、Apple CloudKit 控件和有限的数据收集来降低风险。任何存储或传输系统都无法保证完全安全。保护您的设备和 Apple 帐户，不要发布敏感录音。

11。儿童

Snorz 不适合儿童在没有父母或监护人的情况下公开发布音频。如果您未达到所在国家/地区可以同意使用数字服务的年龄，请仅在父母或监护人的许可下使用 Discover。认为孩子公开了个人信息的家长或监护人应通过下面的私人举报渠道与我们联系。

12。国际加工

Apple、RevenueCat 和 GitHub 可能会在您居住地以外的国家/地区处理信息。他们各自的隐私声明解释了适用于其服务的保护措施和地点。

13。本政策的变更

当 Snorz 发生变化或法律和运营要求发生变化时，本政策可能会更新。当新版本发布时，本页顶部的生效日期将被修改。重大变更也可能在应用程序中或通过应用程序商店发布信息进行传达。

14。联系方式

如有一般问题、隐私、安全或信息安全相关问题，请发送邮件至 support@ajigu.com。除非解决问题确有必要，否则请勿提供敏感信息。
